# Original local scientific-figure example

Purpose: demonstrate a data-linked quantitative plot and a protocol-linked conceptual diagram, with a deliberately wrong diagram for factual review. All inputs are original synthetic fixtures authored for this repository. No study results, participant data, external assets, API calls or generated numerical imagery are involved. The repository license applies.

## Inputs and factual contract

`measurements.csv` has exact headers `time_min,replicate,concentration_mg_L` and triplicate observations at 0, 1, 2 and 3 min. The triplicates are [0,0,0], [1.8,2,2.2], [0.9,1,1.1] and [2.7,3,3.3] mg/L. The calculated means must be [0,2,1,3] mg/L; sample SDs must be [0,0.2,0.1,0.3] mg/L. Every group has n=3. Zero is a valid value; the decrease at 2 min must survive. Missing, nonfinite and duplicate observations fail. Error bars are sample SD using denominator n−1, not SE or confidence intervals. Lines connect means and imply no fitted model.

`protocol.txt` is the authoritative explicit conceptual protocol: collect → fix → stain → image. Only this ordering is supported; no unprovided times, reagents, species, mechanisms or experimental efficacy should be inferred. `erroneous-diagram.json` supplies the planted error collect → stain → fix → image. `generated/erroneous-reference.svg` renders that rejected order and clearly identifies it as a review fixture. A reviewer should detect and explain the reversal before accepting a conceptual figure; `generated/protocol.svg` must follow the text.

## Generation and editable deliverables

Requires Python 3.10+ standard library, with no third-party dependencies or network access. From the package root:

```sh
python3 docs/examples/scientific-figures/generate.py
python3 evals/figure_example_checks.py
```

From an unrelated working directory, use the absolute path to `generate.py` (or the test script). The script locates inputs relative to its own file, so moving the intact package is supported. Optional `--output-dir /absolute/path/to/separate-output` changes only the output location; source directories/ancestors and output-file symlinks and hard links to inputs/generator are rejected. Existing files with the five documented output names in an output directory are regenerated. Do not use an unrelated valuable output directory. Inputs are never intentionally modified.

Outputs in `generated/`: `measurements.svg`, `protocol.svg`, `erroneous-reference.svg`, `statistics.json` and `provenance.json`. SVGs contain editable text, paths and embedded provenance; the editable analysis/rendering source is `generate.py`. JSON contains the actual computed values, source SHA-256 hashes and generator SHA-256. No timestamp or absolute source path enters output bytes, allowing deterministic regeneration across locations. Hashes identify source bytes; they do not authenticate experimental truth. For each generation, verify the hashes against the retained source files.

SVG is supported directly. No PDF, PNG, vector-editor project or proprietary layered source is promised. Fonts may differ among viewers; conversion to other formats must be checked separately. The fixed 900-pixel layout is for this four-time/four-step fixture; longer labels, more steps and larger datasets require a new layout and review. Python’s ordinary floating-point statistics may contain negligible binary rounding in JSON; display labels use six significant digits. Raw observations are retained in CSV and statistics JSON.

## Captions

**Quantitative figure:** Synthetic concentration measurements at 0–3 min, plotted as mean ± sample SD of three replicates per time (n=3; denominator n−1). Concentration is mg/L and time is min. Zero at 0 min and the decrease at 2 min are retained. Lines connect means only. Data: `measurements.csv`; analysis: `generate.py`; exact source hashes: `generated/provenance.json`. These are demonstration data, not observed study results.

**Conceptual figure:** Order specified in the synthetic `protocol.txt`: collect → fix → stain → image. This is a conceptual ordering diagram, not a validated laboratory procedure. No reagent, timing, organism or causal mechanism is asserted. Exact source hashes are in `generated/provenance.json` and embedded in the SVG.

## Verification and review limits

The focused checks use independent expected means/SDs, validate XML, labels/units/n/zero, distinguish the correct diagram from the planted error, verify source hashes, change inputs to test data flow, compare regenerated bytes with committed artifacts, exercise relocation/unrelated cwd and reject unsafe output/missing/duplicate input cases. These are deterministic checks, not model performance tests or rendered visual review.

Rendered visual review is a separate required gate: render each SVG with an available viewer, inspect legibility, clipping, tick labels, error bars including the zero-size bar, retained decrease, arrow direction and conceptual order. Inspect the erroneous reference as a rejected fixture. The authoring script and tests do not establish that this gate passed. The parent review must record its own observed outcome before calling the figure capability visually verified.
