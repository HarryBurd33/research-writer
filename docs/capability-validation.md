Scientific engine assets remain outside this repository. Vina binary identity is locally hashed; an upstream publisher checksum was not available. Boltz source and both assets are pinned; the model asset checksums match publisher metadata. The local CPU environment used Python3.12.14, torch2.15.0 and Boltz2.2.1. The first reduced-step smoke took77.585seconds and sampled peak process-tree RSS5,418,958,848bytes on a16GiB Mac. Memory sampling may miss transient peaks; tracked-PID cleanup when process-group signaling is denied has the same transient-descendant limitation. No hard sandbox or universal hardware bound is claimed.

A repeated-run preflight exposed Numba caches inside the verified source checkout. The wrapper now routes JIT caches into its owned run directory; the failed preflight is retained and post-run inspection confirmed no extra source files. The earlier output/source-overlap defect was reproduced and fixed before inference. Independent review checked the run-level nonmutation regression. Slurm terminal-cause review distinguishes worker timeouts from a successfully exiting scheduler controller.

The draft release adds native/platform tests separately from the existing required aggregate. Initial legacy core jobs reached portable-bundle checks successfully but failed because the first draft had not yet regenerated the bundle. This is an integration failure, not a passing release. Final claims require regenerated-package checks, relevant regressions, independent review and exact installed/source/GitHub readback. No private inputs, local paths, model assets, credentials or raw private research are included.
