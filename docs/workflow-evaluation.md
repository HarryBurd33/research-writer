# Phase 5: research-to-writing evaluation

Evaluated 2026-10-28. Baseline v0.8.0; candidate v0.9.0. This report describes
executed bounded controls, not broad scientific or writing-quality validation.

## What changed and why

The baseline met all critical requirements in ten cases but missed an explicit
spillover account in a proposal. A separately frozen fresh group-training case
recognized exposure yet lacked a practical prevention/measurement response. The
focused change in `references/modes.md` now asks for material cross-condition
exposure, a practical response and remaining dependence/interpretation limits.
It explicitly preserves individual assignment when tasks are independent.
No existing installed Python algorithm, engine or device default changed.

The observed changes are specific: P5-08 now explains exposure and a mitigation;
P5-F01 now offers practical prevention/measurement. P5-F02 retains a suitable
individual design. All other applicable criteria remained met. Full source/input
and output integrity, the independently frozen numerical reference, and both
requested local artifact readbacks were checked separately.

The ten-case packet covers missing intake, feasible quantitative synthesis,
refusal of unsupported pooling, corrected/conflicting sources, theory, tutorial,
close reading, prospective study design, duplication and a bounded primary-paper
review. Four reports in the numerical fixture represent three declared families;
the common-effect teaching estimate is 1.77778 seconds saved, SE0.66667, normal
95% interval[0.47114,3.08442]. This is synthetic data, not empirical evidence.

## Separate evidence gates

- Deterministic local suites: all125 methods passed with applicable selected
  CPU engines, including sixteen new fixture/arithmetic methods. The initial
  real-SSH attempt ran zero methods because the sandbox denied its127.0.0.1
  bind; the identical explicitly authorized isolated fixture passed6/6 outside
  that sandbox. Both outcomes are retained. No production host was contacted.
- Independent extra controls:11 arithmetic/integrity,9 live-source/local-delivery
  and7 static patch-scope checks passed. These are distinct evidence categories.
- The arithmetic helper uses only Python3.10+ standard library. CI fixture tests
  do not run an LLM or semantically grade prose. Package self-check and portable
  consistency passed; hostedCI and final installed-copy identity are separate
  release gates recorded in the pull request.
- The paired primary-paper review used identical original notes from inspected
  Lewis2020/Self-RAG primary versions. Executors did not browse or claim personal
  full-text access. A separate live check actually searched once and inspected
  selected sections of Lewisv4 and Shuster2021; a newer context-sufficiency paper
  remained an abstract-only lead. A new local brief was saved, reread and
  independently audited. This was bounded exploration, not systematic coverage
  or a fresh GoogleDocs integration.

## Comparison limits and remaining work

Review was separate from construction, nonblind and agent-based; no human expert
validation occurred. Exact model/effort were unavailable and inherited. Each arm
used one ten-case context and a separate two-case context. An initial candidate
context received both packets; it was interrupted before any response artifact,
retained as diagnostic and excluded. Fresh matched contexts supplied the accepted
results. These small runs establish the observed narrow benefit and regression
coverage, not a general effect size, model superiority or cost savings.

Core intake, audience/genre/venue decisions, renewed searches, nearest-neighbor
and duplication checks, source restrictions and device adaptation remain. The
[remaining roadmap](roadmap.md) covers deeper retrieval/source support, optional
enforced Linux isolation, actual external-host/GPU acceptance, selected engine
benchmarks and separate Windows/scheduler support. Searches cannot guarantee
novelty or completeness; numerical provenance is not scientific truth, and
prediction is not experimental validation.
