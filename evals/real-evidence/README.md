# Real-evidence reproducibility example

Run `python3 reproduce.py` from this directory (or invoke the script by path). It uses only the Python standard library, reads the adjacent CSV, validates frozen counts and estimates, and prints actual estimates and every leave-one-site-out result as JSON. It does not download anything.

This example comes from a completed **closed-corpus evidence review and meta-analytic reanalysis** of loss versus gain framing in all 36 independent site samples of Many Labs 1. It is not a fieldwide systematic review, 36 separate publications, or evidence of performance across all research domains. Feasibility scoping preceded a locally frozen protocol; three subsequent web queries returned 18 records: 16 outside the corpus, one duplicate report with a mismatched attachment, and one erratum consulted. The original report and data were followed directly. Screening, extraction and appraisal were performed by one agent; a separate review independently reproduced the raw cell vectors and numerical results.

## Original sources and extraction

- Klein et al. (2014), [original article, DOI 10.1027/1864-9335/a000178](https://doi.org/10.1027/1864-9335/a000178). An accessible [journal PDF mirror](https://stanford.edu/~knutson/jdm/klein14.pdf) gives the framing task on p. 145, procedure/analysis on p. 147, and sample/results summaries in Tables 1–3.
- [Author data repository](https://github.com/ManyLabsOpenScience/ManyLabs1): [MLforR.xlsx](https://github.com/ManyLabsOpenScience/ManyLabs1/blob/master/MLforR.xlsx), sheet `Gain_Loss`, site rows 4–39. Aggregate rows were excluded to avoid counting participants twice. The CSV contains only site identifiers, mode and aggregate counts; no participant records.
- Header orientation was checked against the [original labeled data](https://github.com/ManyLabsOpenScience/ManyLabs1/blob/master/Data/Tab.delimited.Cleaned.dataset.WITH.variable.labels.dat), [numeric data](https://github.com/ManyLabsOpenScience/ManyLabs1/blob/master/Data/Tab.delimited.Cleaned.dataset.WITH.variable.values.dat) and [codebook](https://github.com/ManyLabsOpenScience/ManyLabs1/blob/master/Data/Codebook.xlsx). Workbook columns B/C/D/E actually represent loss/certain, gain/certain, loss/risky, gain/risky, despite misleading headings. `gainlossgroup` 0 = “People will die” (loss), 1 = “People will be saved” (gain); response 2 is the probabilistic/risky option. Every site's four cells and missing count matched after this correction.
- [2019 erratum metadata](https://research.tilburguniversity.edu/en/publications/erratum-correction-to-klein-et-al-investigating-variation-in-repl/), DOI 10.1027/1864-9335/a000373, pp. 211–213. The publisher-supplied appended correction was inspected through a [ResearchGate mirror](https://www.researchgate.net/publication/259310513_Investigating_Variation_in_Replicability) after publisher access failed. It corrects the Rugg effect and an anchoring count, leaving the framing endpoint unchanged.
- The authors release the data under [CC0](https://github.com/ManyLabsOpenScience/ManyLabs1/blob/master/Data/Data%20released%20under%20CC0%20license.txt). This CSV is an aggregate extraction of those data. The Python implementation is original; upstream analysis code was not copied.

## Analysis and limits

For each site, log OR = log[(loss risky × gain certain)/(loss certain × gain risky)]; its variance is the sum of the four reciprocal cell counts. All cells are positive. The script computes common-effect inverse-variance and DerSimonian–Laird random-effects estimates with normal 95% intervals, Cochran Q, Q-based I², tau² and leave-one-site-out estimates. Expected results are 6,271 observed responses, 73 missing, random-effects OR **3.3245 (95% CI 2.9677–3.7242)**, Q **37.0116** (35 df), I² **5.4351%**, tau² **0.0063564**. The original paper used a different effect measure/model; this does not claim to reproduce its Cohen-d/REML summary.

This is one transparent analytic choice, not a universal meta-analysis method or a substitute for searching and appraising a new question. The hypothetical single-choice task, convenience samples, missing responses, shared methods and translations limit generalization. The exact allocation implementation was not independently audited. Distinct session IDs do not prove unique people. Odds ratios do not express a tripling of probability. Low observed heterogeneity does not remove these limitations; the result does not establish effectiveness of a real-world intervention.
